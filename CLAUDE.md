## 1. Project in one paragraph

**Project V** studies whether explanations of RL manipulation policies remain faithful under dynamics shift, and whether shifts in those explanations predict failure. Policies: SAC+HER on Gymnasium-Robotics `FetchReach` / `FetchPush` (MuJoCo), trained under three conditions (NoDR, DR, DR+History). Contributions:

| ID | Contribution | Module |
|---|---|---|
| C1 | Closed-loop vs open-loop faithfulness of state attributions, with analytic ground truth (Cartesian P-controller) and a planted-shortcut policy | `projectv/xai/faithfulness.py` |
| C2 | GWIE-C: Gradient-Weighted Iterative Erasure for continuous Gaussian policies over semantic feature groups | `projectv/xai/gwie_c.py` |
| C3 | Attribution-Shift Monitor (ASM): early failure prediction on held-out dynamics vs 5 baselines | `projectv/monitor/` |
| C4 | How dynamics DR changes feature/temporal reliance + linear probes for implicit system identification | `projectv/analysis/` |

Transfer claim is **sim-to-sim held-out dynamics**. Never write "sim2real transfer achieved" anywhere (code, README, report).

## 6. Environment facts (verify with asserts; do not trust this table blindly)

Fetch envs return a dict: `observation`, `achieved_goal`, `desired_goal`. Action: 4-D `[dx, dy, dz, gripper]` in [-1, 1] (mocap end-effector displacement). Episode length 50. Success: `info["is_success"]` at the final step.

`FetchPush` `observation` (25-D), expected order — assert in `obs_layout.py` against the env source on Day 1:

| Slice | Group name | Meaning |
|---|---|---|
| 0:3 | `ee_pos` | gripper position |
| 3:6 | `obj_pos` | object position (== `achieved_goal`) |
| 6:9 | `obj_rel` | object − gripper |
| 9:11 | `grip_state` | finger positions |
| 11:14 | `obj_rot` | object Euler |
| 14:17 | `obj_velp` | object linear vel (relative) |
| 17:20 | `obj_velr` | object angular vel |
| 20:23 | `ee_vel` | gripper linear vel |
| 23:25 | `grip_vel` | finger vel |
| `desired_goal` | `goal` | target |
| `achieved_goal` | merged into `obj_pos` | duplicate |

`FetchReach` `observation` is 10-D: `ee_pos`, `grip_state`, `ee_vel`, `grip_vel`.

**Redundancy:** `obj_rel = obj_pos − ee_pos` and `achieved_goal == obj_pos`. Attribution code must (a) group `achieved_goal` with `obj_pos`, and (b) additionally report the redundant cluster `{ee_pos, obj_pos, obj_rel}` erased jointly.

**Fetch uses mocap control**, so arm joint dynamics barely affect behaviour. "Actuator gain" DR is implemented as an action-scale multiplier in `dr_wrapper.py`; document this honestly.

## 7. Experimental conventions

- **Seeds:** training seeds `{0,1,2}` (MVP). Eval episodes seeded `base_seed = 10_000 * train_seed + cell_id * 1_000 + ep`.
- **Data splits for C3:** for each policy, rollouts are split into `calib` (fit nominal stats, choose thresholds/EWMA α) and `test` (report). Never fit anything on `test`.
- **DR resampling:** at every `reset()`. Parameters written to `info["dr_params"]` and logged per episode.
- **History condition:** `history_wrapper` stacks the last k=4 `observation` vectors plus the last 3 actions into the `observation` key; `desired_goal`/`achieved_goal` stay current-only so HER relabelling is unaffected.
- **Checkpointing:** every 50k env steps → `results/ckpt/{exp}_s{seed}/step_{n}.zip` + replay buffer (`save_replay_buffer`) every 200k. `--resume auto` picks the latest. Kaggle sessions can die; every run must survive a restart.
- **Per-step logging** (`steplog.py`, `.npz` per cell): obs dict, action mean, log_std, sampled action, min-Q, actor penultimate activations, DR params, `is_success`, step index.
- **Stats:** success per (policy, cell) = mean over ≥100 episodes. Across seeds: mean + 95% stratified bootstrap CI (`rliable`, 2,000 resamples, strata = cells); always also print per-seed values (n=3 makes IQM degenerate — say so). AUROC CIs: cluster bootstrap over episodes, resampling seeds first.

## 8. Attribution conventions

- **Function explained:** `policy_fn.py` exposes `mu(x_flat) -> action mean (pre-tanh and post-tanh variants)` and `q(x_flat, a)` built from `model.policy.actor.get_action_dist_params(obs_dict)` and `model.policy.critic`. Flat ↔ dict conversion lives only in `policy_fn.py`.
- **Scalar target for gradients:** `f(s') = <mu(s'), mu(s)/||mu(s)||>` (projection onto the current action direction). Do not differentiate a KL/L2 distance at s'=s — its gradient is zero.
- **Divergence for erasure effects:** `D = KL(N(mu(s), σ(s)) || N(mu(s'), σ(s')))` (diagonal Gaussian, pre-tanh).
- **Baselines / erasure operator:** `marginal` = resample the group's values from the calib-split state pool (M=8 samples, average); `mean` = replace with pool mean. Report `marginal` as primary. Never use zero baselines for positions.
- **Units:** attribute in raw observation units. If an obs normaliser is ever added, compose it inside `policy_fn`.
- **Methods:** `grad`, `grad_x_delta`, `ig` (16 steps, marginal-mean baseline), `smoothgrad` (σ = 0.1·feature std, n=16), `occlusion` (group erasure, marginal), `kernelshap_grouped` (≤512 coalitions), `gwie_c`.
- **Aggregation:** group attribution = sum of |per-feature attribution| within group; share = group / total.

### GWIE-C (C2) reference algorithm
```
input: state s, groups G, scalar target f, divergence D, erasure op E
s_cur ← s ; remaining ← G ; A ← {}
for k in 1..|G|:
    for g in remaining: score[g] ← Σ_{i∈g} | ∂f/∂s_i (s_cur) · (s_cur_i − base_i) |
    g* ← argmax score
    s_next ← E(s_cur, g*)                     # erase g* (marginal resample, averaged)
    A[g*] ← D(π(·|s) || π(·|s_next)) − D(π(·|s) || π(·|s_cur))   # marginal divergence gain
    s_cur ← s_next ; remaining ← remaining \ {g*}
return A (normalised), erasure order
```
**Step 0 (before writing `gwie_c.py`):** the pseudocode above is a provisional reference written without access to the original. The authoritative GWIE (Gradient-Weighted Iterative Erasure) lives in the user's DePlag codebase on their machine.
1. Ask the user for the DePlag repo path (or search their projects folder for `GWIE` / `gwie` / `iterative_erasure` if they approve).
2. Read the original implementation fully and write a short summary to `docs/gwie_original.md`: score/weighting formula, erasure operator and baseline, iteration order, stopping rule, final attribution formula.
3. Adapt that mechanism to continuous Gaussian policies over feature groups (`gwie_c`), changing only what the modality requires (tokens → feature groups; class logit → scalar target `f` / divergence `D` above). List every deviation in `docs/gwie_original.md`.
4. Also keep a direct port (`gwie_orig_port`) if any deviation is non-trivial, and report both in C1/C2 tables.
Do not claim GWIE lineage in README/report for any variant whose deviations are undocumented.

## 9. Code rules

- Python, type hints, `ruff` + `black` (line length 100). Pure functions in `xai/`, `monitor/`, `analysis/`; no global state.
- Configs are YAML, loaded once, hashed (`config_hash`) into every output path's `run_meta.json`.
- No notebook logic: notebooks only call `projectv` modules and scripts.
- Tests that must pass before any commit touching the relevant module:
  - `test_wrappers.py`: DR params actually change `model.geom_friction` / `body_mass`; latency delays actions by exactly k; history shapes correct; HER `compute_reward` still works through wrappers.
  - `test_attr_sanity.py`: on a hand-built linear policy `a = W s`, `grad_x_delta` and `ig` equal the analytic contributions (atol 1e-5); on the analytic controller, zero attribution on object groups.
  - `test_gwie.py`: on a policy that depends only on group X, GWIE-C erases X first and assigns ≥0.95 share to X.
  - `test_monitor.py`: AUROC = 1.0 on a synthetic separable stream, 0.5±0.05 on shuffled labels.
- Commits: small, imperative messages, one concern each. Push to GitHub so Kaggle can clone.
